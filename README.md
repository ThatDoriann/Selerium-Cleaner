# Selerium-Cleaner
A free, open-source cleaner utility for Roblox that is written in python. Basic script that looks for Roblox on the disc and deletes it, then reinstalls Roblox. Very efficient, and simple. Feel free to use for your projects as long as you credit me!

You may need to install the dependencies yourself.

If you're wondering why it's not v1.0 but instead v2.0, this is actually a rewrite of a Roblox cleaner tool I made in 2024, however that tool is now outdated and the code was very messy and unstructured. I decided to rewrite it 2 years later, and stripped out all the unnecessary features. If you find any issues or have suggestions, please contact me on my discord.
